¿Qué aprendió?

01 Fundamentos de Web

Durante la asignatura aprendí cómo funciona la web desde la base. Comprendí la diferencia entre tecnologías nativas y tecnologías web, cómo viaja la información por Internet mediante los protocolos TCP e IP, así como la importancia de estándares como HTTP, HTML, CSS y JavaScript. Asimismo, entendí el rol del desarrollador Front-end, Back-end y Full-Stack, y aprendí a usar Git y GitHub para el trabajo colaborativo teniendo también trazabilidad del código.

  • TCP e IP
  • HTTP
  • HTML
  • CSS
  • JavaScript
  • Front-end
  • Back-end
  • Full-Stack
  • Git y GitHub
02 Diseño de Interfaces

En cuanto al diseño de interfaces, aprendí a estructurar páginas con HTML5 y a dar estilo con CSS3, empleando modelo de caja, unidades relativas, Flexbox y Grid para lograr diseños responsivos. Luego conocí dos enfoques de trabajo con librerías, el de componentes ya creados con Bootstrap y el de utilidades atómicas con Tailwind CSS. Asismimo, reforcé conceptos de accesibilidad y SEO, validándolos con Google Lighthouse y WAVE.

  • HTML5
  • CSS3
  • Flexbox
  • Grid
  • Bootstrap
  • Tailwind CSS
  • Accesibilidad
  • SEO
03 Programación

En programación, comprendí cómo funciona JavaScript con las variables de ámbito de bloque, funciones flecha, closures y manipulación del DOM, además de las ventajas del tipado estático de TypeScript y el uso de la API Canvas para animaciones. Finalmente, aprendimos sobre React, entendiendo las Aplicaciones de Página Única, el Client Side Rendering, desarrollo basado en componentes con JSX, props y children, el renderizado condicional e iterativo, así como el enrutamiento con React Router y el consumo de APIs con async/await y Axios.

  • JavaScript
  • TypeScript
  • API Canvas
  • React
  • JSX
  • React Router
  • async/await
  • Axios

¿Cómo aprendió?

01 Trabajo Semanal

El aprendizaje se ha ido desarrollando en cada semana. En la hora de teoría se explicaron los fundamentos y definiciones del tema. En la hora de práctica se aplicaron dichos conceptos con ejercicios y luego se reforzaron con las prácticas de laboratorio y prácticas calificadas. En cada semana se ha ido actualizando el cuaderno de la asignatura.

  • Teoría
  • Práctica
  • Laboratorio
  • Prácticas calificadas
  • Cuaderno
02 Trabajo en equipo

Las prácticas calificadas grupales también han sido fundamentales, pues se con ramas de GitHub por integrante, lo que permitió practicar el cómo los desarrolladores trabajan en la vida real teniendo una mejor trazabilidad del aporte de cada uno. Asimismo, se publicaron los proyectos en GitHub Pages para verlos en funcionamiento.

  • Ramas de GitHub
  • Trazabilidad
  • GitHub Pages
03 Portafolio

También se validó la calidad mediante las herramientas de Google Lighthouse y WAVE para rendimiento, accesibilidad y SEO, DevTools del navegador para visualizar peticiones de red, así como React DevTools para revisar el estado de los componentes. Finalmente, la construcción de este portafolio permitió consildar lo aprendido semana a semana aplicando los conceptos de la asignatura.

  • Google Lighthouse
  • WAVE
  • DevTools
